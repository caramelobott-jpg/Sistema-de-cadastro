# Banco Elevoler

Um projeto simples de cadastro de usuários desenvolvido em Python, com validações básicas e armazenamento de dados em arquivos JSON.

## Sobre o projeto

O Banco Elevoler é um sistema de cadastro criado para praticar conceitos de programação em Python, como funções, condicionais, manipulação de arquivos, listas, dicionários e tratamento de exceções.

O programa solicita os dados do usuário, realiza verificações básicas e salva os cadastros em um arquivo JSON.

## Funcionalidades

- Cadastro de nome, idade e Gmail.
- Validação básica do nome.
- Verificação de idade mínima de 18 anos.
- Verificação do Gmail.
- Armazenamento dos cadastros em JSON.
- Utilização de funções para organizar o código.
- Tratamento de exceções com `try` e `except`.

## Tecnologias utilizadas

- Python
- JSON

## Estrutura do projeto

```text
Banco-Elevoler/
├── __pycache__/
├── cadastro.json
├── cadastros.json
├── funcoes.py
└── main.py
```

## Como funciona

1. O programa solicita o nome do usuário.
2. Solicita a idade.
3. Solicita o Gmail.
4. Realiza verificações básicas dos dados.
5. Se os dados forem válidos, salva o cadastro no arquivo JSON.

## Objetivo

Este projeto foi desenvolvido como prática de aprendizado em Python, buscando melhorar a lógica de programação, a organização do código e o uso de arquivos para armazenamento de dados.
